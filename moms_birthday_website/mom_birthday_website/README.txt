# Mom's Birthday Website ❤️

A self-contained, phone-first birthday experience.

## Add the photos
Put your photos inside `assets/` and name them:
- photo1.jpg
- photo2.jpg
- photo3.jpg
- photo4.jpg
- photo5.jpg
- photo6.jpg

You can use PNG/WebP too, but update the filenames in `script.js`.

## Add the song
Put an audio file in `assets/` named:

birthday-song.mp3

Or change `MUSIC_FILE` at the top of `script.js`.

## Change the letter
Open `index.html` and edit the paragraphs inside `.letter-content`.

## Run it
The easiest way is to open `index.html` in a browser.

For reliable audio behavior, especially on phones, upload the folder to any static web host or run a tiny local server.

The site is entirely front-end: HTML + CSS + JavaScript. No database or paid service is required.
