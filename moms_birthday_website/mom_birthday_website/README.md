# Mom Birthday Website

A heartfelt birthday webpage with a cinematic gift reveal, memory gallery, letter, and music.

## Run locally

From this folder, start a simple local server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000/index.html
```

## Files

- `index.html` – page structure and content
- `style.css` – layout, animation, and styling
- `script.js` – gallery loading, music, secret messages, and interactions
- `assets/` – images and audio files

## Notes

This project is designed to be served over HTTP instead of opened directly as a local file because browser media playback is more reliable that way.
